# 감정 탐색 서비스 스펙

상태: 핵심 목적 합의, 상세 기능 계약과 MVP 범위 미정. 기록일: 2026-11-01.

## 합의한 핵심 경험

사용자가 감정을 말하면 AI가 후속 질문을 계속 생성하여 사용자가 내면에 어떤 감정이 있었는지 탐색하도록 돕습니다. AI가 감정을 확정적으로 판정하는 기능으로 정의하지 않습니다.

개념 흐름: 감정 표현 → AI 질문 → 사용자 답변 → 이어지는 AI 질문. 질문 생성 전략, 대화 문맥 유지 방식과 종료 조건은 아직 정하지 않았습니다.

위 기능 전체가 MVP로 확정된 것은 아닙니다. 이번에 구현한 것은 [백엔드 실행 기반](../backend-bootstrap/spec.md)입니다.

## LLM 결정 상태

사용자 요청에 따라 제공자, 모델명, API 키는 빈 값으로 유지합니다. SDK·프롬프트·질문 생성 API·모델 호출은 추가하지 않았습니다. 특정 업체나 모델, 외부 호출 비용은 승인하거나 확정하지 않았습니다.

## 기능 구현 전에 정할 사항

- MVP에 포함할 기능과 우선순위
- 대화 시작·종료 기준, 질문 수와 질문 전략
- 답변을 다음 질문에 반영하는 문맥 범위
- 사용자 식별과 인증·권한
- 감정·질문·답변의 저장 시점, 열람·수정·삭제·보관 정책
- 요청·응답 계약, AI 실패·지연 처리
- 음성 처리와 클라이언트·백엔드의 책임
- 조언·추천·분석의 입력 및 출력 기준

상세 배경과 사용자 흐름은 [서비스 기획안](../../docs/service-overview.md), 기능별 요구사항은 [기능 명세서](../../docs/features.md)를 기준으로 이어갑니다.
