# 01. 백엔드 대화 턴 제어 및 상태 머신

Type: grilling
Status: resolved

## Question

7단계 상담 라이프사이클의 진행을 LLM 자율 에이전트에 위임할 것인가, 아니면 백엔드가 대화 세션 상태(`currentStep`)를 엄격히 추적하며 단계별 전용 프롬프트를 주입하여 제어할 것인가?

## Answer

백엔드가 세션의 `currentStep` 상태 머신을 엄격히 관리하고, 단계별로 제약된 전용 시스템 프롬프트(목적, 필수 수집 데이터, 금지 사항)를 주입하는 방식을 채택한다. 이를 통해 모델의 환각, 단계 건너뛰기, 상담 이탈을 방지하고 예측 가능한 대화 품질과 안전성을 확보한다.
