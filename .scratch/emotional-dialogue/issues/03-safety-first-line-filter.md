# 03. 위기 신호 1차 서버 인메모리 감지 필터

Type: grilling
Status: resolved

## Question

자해·자살·타해 등 긴급 위기 신호를 감지하기 위해 외부 AI 호출 전 1차 서버 필터를 어떻게 구현하고 일상 관용 표현을 어떻게 처리할 것인가?

## Answer

외부 AI 호출 지연, 비용 발생 및 필터링 누락을 원천 차단하기 위해, 백엔드 내부의 정규식(Regex)과 고위험 키워드 사전 기반 인메모리 검사 컴포넌트를 구현한다. 메시지 수신 즉시 1차 검사를 수행하며, 일상적 관용 표현("과제 때문에 죽겠다 ㅋㅋ" 등)의 예외 화이트리스트 패턴을 포함하여 오탐을 방지한다. 위기 감지 시 AI 호출을 즉시 차단하고 핫라인 안내 응답을 반환한다.
