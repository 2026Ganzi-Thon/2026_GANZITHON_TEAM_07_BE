# 06. STEP 06 말랑이 추천 및 감정 요약 알고리즘

Type: grilling
Status: resolved
Blocked by: 01, 05

## Question

STEP 06에서 추천 말랑이(슬랑이, 스퀴시, 왁뿌볼)를 선정할 때 순수 룰 기반(대표 감정에 따른 1:1 매핑)으로 할 것인가, 아니면 전체 대화 내용과 감정 강도 변화를 분석한 LLM의 추천 추론을 결합할 것인가?

## Answer

서비스 일관성과 신뢰성을 위해 추천 캐릭터 결정은 대표 감정 기반의 백엔드 도메인 룰(불안/우울➔슬랑이, 속상함/슬픔➔스퀴시, 분노/스트레스➔왁뿌볼)로 확정하고, 사용자 맞춤형 추천 사유 및 공감 멘트는 전체 대화 맥락을 고려하여 LLM이 자연스럽게 생성하는 하이브리드 방식을 적용한다.
