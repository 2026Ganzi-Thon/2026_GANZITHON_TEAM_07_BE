## 조사 질문과 결론

소크라테스식 질문, CBT, SFBT의 질문 방식을 AI 감정 대화에 참고할 수 있는지,
그 실행을 BE에서 어떻게 통제할지 검토했습니다.

이 자료는 질문을 선택하는 설계의 근거입니다. 상담 전문가용 기법의 근거를
AI 감정 대화의 치료 효과나 진단 능력에 대한 검증으로 옮겨 해석하지 않습니다.

초기 설계로는 BE가 허용된 실행과 상태를 관리하고 모델이 그 범위에서
다음 질문을 제안하는 방식을 권합니다. 이는 아래 근거를 종합한 **설계 추론**입니다.

## 1. 유도된 발견은 논쟁이나 정답 설득과 구분한다

**확인한 내용:** Beck Institute의 평가 자료는 근거·대안·장단점을 탐색해
내담자가 자기 결론을 얻도록 돕는 접근을 긍정적으로 평가합니다.
논쟁·설득·심문과 관점 강요는 낮게 평가합니다.
[근거: Work Sample Guide, CTRS Guided Discovery, 문서 p.12](https://beckinstitute.org/wp-content/uploads/2021/08/Work-Sample-Guide.pdf).

**설계 추론:** 질문의 성공 기준을 ‘사용자가 생각을 바꿨는가’로 두지 않습니다.
사용자 발언에 근거해 탐색했는지, 답을 강요하지 않았는지, 정정을 수용했는지를 평가합니다.

## 2. 기법 선택은 현재 상황과 사용자 선호를 반영한다

**확인한 내용:** Judith Beck은 기법 선택에 사용자 선호, 현재 문제, 이전 반응과
협력적 결정을 고려한다고 설명합니다. 생각이 정확할 때는 수용도 선택지로 다룹니다.
[근거: Selecting Techniques in CBT](https://beckinstitute.org/blog/selecting-techniques-in-cbt/).

**설계 추론:** ‘명료화 → 근거 → 반례 → 재해석’을 모든 대화에 강제하지 않습니다.
실제 부당한 대우를 말하는 사용자에게 먼저 다른 해석을 요구하는 응답은 별도 평가 사례로 둡니다.
사용자가 탐색을 원하지 않으면 공감·정리·중단으로 전환할 수 있어야 합니다.

## 3. SFBT는 목표와 자원에 관한 대화를 참고할 수 있다

**확인한 내용:** SFBTA 3판 매뉴얼은 사용자 관점을 배우는 태도,
원하는 미래, 예외, 척도 질문, 대처 대화를 설명합니다.
척도 질문에서는 무엇을 평가하는지와 양 끝점의 뜻을 정합니다.
[근거: SFBTA Treatment Manual 3rd Edition, 문서 pp.16, 19~24, 29](https://www.sfbta.org/Solution%20Focused%20Therapy%20Treatment%20Manual%20for%20Working%20with%20Individuals%20-3rd%20Edition-%20final.pdf).

**설계 추론:** 자원·예외·작은 행동을 탐색하는 질문을 선택지로 둘 수 있습니다.
단, 모든 대화를 점수 질문으로 시작하거나 긍정적인 대답을 요구하지 않습니다.
점수를 기록한다면 ‘감정 강도’, ‘목표에 가까운 정도’, ‘실행 자신감’을 구분합니다.
서로 다른 척도 점수를 하나의 감정 변화 그래프로 합치지 않습니다.

## 4. 에이전트와 워크플로는 실행 권한의 위치가 다르다

**확인한 내용:** Anthropic은 코드가 정한 경로로 모델·도구를 실행하는
워크플로와, 모델이 과정·도구 사용을 동적으로 결정하는 에이전트를 구분합니다.
단순한 방식부터 시작하고, 평가로 필요성이 확인될 때 복잡도를 늘리도록 권합니다.
[근거: Building effective agents](https://www.anthropic.com/research/building-effective-agents).

**설계 추론:** 이 제품은 다음과 같이 역할을 나누는 방식으로 시작할 수 있습니다.

- BE: 사용자별 문맥 접근, 허용된 질문 행동, 실행 횟수·시간 제한, 결과 검증과 저장 적용
- 모델: 주어진 문맥에서 탐색 목적 선택, 질문 문장 제안, 근거 발언을 붙인 상태 변경 제안
- 사용자: 질문 거절, 정정, 주제 변경과 종료

역할을 나눴다는 이유만으로 여러 모델이나 여러 에이전트를 도입할 필요는 없습니다.
워크플로 안에서 질문 선택의 유연성을 확보한 뒤 품질·지연·비용으로 확장 여부를 판단합니다.

## 5. 제품 설계로 별도 정의해야 할 항목

다음은 임상 원문을 그대로 구현한 규칙이 아니라 **제품 설계 제안**입니다.

| 항목 | 제안 | 검증 또는 미정 사항 |
| :--- | :--- | :--- |
| 사실과 해석 | 사용자 원문과 모델 추론을 구분하고 발언 근거를 연결 | 추론이 장기 기록의 사실로 굳어지지 않는지 확인 |
| 대화 흐름 | 질문 유형을 선택·반복·건너뛰거나 공감으로 돌아갈 수 있게 구성 | 강제 단계 진행과 반복 질문 평가 |
| 질문 부담 | 한 번에 주요 질문 하나를 제안 | 실제 사용자 반응으로 조정 |
| 척도 | 평가 대상·양 끝점 의미를 함께 유지 | 서로 다른 척도 혼합 여부 확인 |
| 중단과 정정 | 종료·거절·주제 변경을 상태에 반영 | 다음 턴에 이전 질문을 강요하지 않는지 확인 |
| 위기 분기 | 위기 신호가 있으면 일반적인 반례·재해석 탐색을 멈추는 별도 경로 마련 | 전문가 검토, 대응 문구·지역 지원 연결·오탐·누락 기준 미정 |
| 실행 제한 | 모델 호출과 재생성에 상한을 두고 실패 시 보수적인 응답 사용 | 실제 모델로 지연·실패·누락 평가 필요 |
| 장기 개인화 | 확인되지 않은 해석을 성격·취약점으로 확정하지 않음 | 보관·삭제·장기 문맥 활용 정책 미정 |

위기 분기는 이 조사에서 검증된 자동 위기평가 도구를 뜻하지 않습니다.
진단·치료 수행, 응급 판단의 보장, 인간 상담자의 상시 연결을 가정하지 않습니다.

## 확인하지 못한 주장과 적용 한계

- 사용자가 제시한 ‘소크라테스식 4단계’와 ‘CBT 임상 3단계’가 모든 상황에
  적용되는 단일 표준이라는 근거는 이번 조사에서 확인하지 않았습니다.
- 제시된 ‘인지치료 주요 가정 14가지’ 전체의 원출처와 일치 여부는 검증하지 않았습니다.
  이를 모델의 절대 규칙이나 사용자를 판단하는 기준으로 채택하지 않습니다.
- ‘왜’ 표현을 줄이는 문체는 제품 선택이 될 수 있지만 단어만 바꿔도
  심문이나 설득 문제가 해결된다고 해석하지 않습니다.
- 상담 전문가 대상 자료는 AI 제품의 치료 효과, 위기 탐지 성능,
  10대 사용자에 대한 적합성을 검증한 자료가 아닙니다.
- 외부 모델 호출·실험·임상 검증은 수행하지 않았습니다.
  제공자·모델·SDK 선택과 유료 호출 승인도 포함하지 않습니다.

## 후속 평가 자료

가상의 대화 사례로 발언 충실성, 질문의 비유도성, 거절·정정 수용,
위기 분기와 척도 의미 보존을 검토할 수 있습니다.
이 평가는 대화 정책의 준수 확인이며 임상적 유효성 검증과 구분합니다.
