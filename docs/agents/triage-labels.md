# Triage labels

| Role | Local Status value | Meaning |
| --- | --- | --- |
| needs-triage | needs-triage | Maintainer evaluation needed |
| needs-info | needs-info | Waiting for reporter information |
| ready-for-agent | ready-for-agent | Specified and ready for an agent |
| ready-for-human | ready-for-human | Requires human implementation |
| wontfix | wontfix | Will not be actioned |

Record the matching value as `Status: <value>` near the top of each local issue.
For example, `Status: ready-for-agent`. Do not create GitHub labels for local tickets.
