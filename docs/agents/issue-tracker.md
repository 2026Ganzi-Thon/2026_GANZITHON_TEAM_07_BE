# Issue tracker: GitHub

Issues and specs live in `2026Ganzi-Thon/2026_GANZITHON_TEAM_07_BE`.

Use the gh CLI. Always pass
`--repo 2026Ganzi-Thon/2026_GANZITHON_TEAM_07_BE`
because this clone also has a personal fork remote.

- Read: gh issue view <number> --repo <repo> --comments
- List: gh issue list --repo <repo>
- Create: gh issue create --repo <repo> --title "..." --body-file <file>
- Label: gh issue edit <number> --repo <repo> --add-label "..."
- Close: gh issue close <number> --repo <repo>

Publishing to the issue tracker means creating a GitHub issue.
Fetching a relevant ticket means reading its body and comments.
