## 현재 상태

현재 저장소에는 문서와 협업 설정만 있습니다. Spring Boot 프로젝트, 빌드 설정, 실행·테스트 명령은 아직 추가되지 않았습니다.

## 저장소 가져오기

소스 확인용 클론:

```bash
git clone https://github.com/2026Ganzi-Thon/2026_GANZITHON_TEAM_07_BE.git
cd 2026_GANZITHON_TEAM_07_BE
```

코드를 기여할 때는 GitHub에서 개인 포크를 만든 뒤 해당 포크를 `origin`, 팀 저장소를 `upstream`으로 설정합니다. [협업 워크플로](agents/workflow.md)에 따라 작업 브랜치와 worktree를 만들고 PR을 보냅니다.

## 실행 및 검증 절차

Spring Boot 프로젝트 구성 후 다음 항목을 실제 실행 결과에 맞춰 작성합니다.

1. 필요한 JDK와 외부 서비스 준비
2. 로컬 환경변수 및 실행 프로필 설정
3. 의존성 설치와 빌드
4. 애플리케이션 실행 및 접속 주소 확인
5. 테스트 명령과 성공 기준 확인

API 확인 방법과 명세서 주소는 [API 명세서](api.md)에 함께 기록합니다.
