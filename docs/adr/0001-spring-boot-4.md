# 신규 백엔드에 Spring Boot 4.x 채택

초기 후보는 Spring Boot 3.x였지만, 3.5.x의 OSS 지원 종료를 확인하고 신규 프로젝트의 유지보수를 위해 지원 중인 4.x를 채택했습니다. Java 21을 사용하며 Swagger UI는 Boot 4.1.x와 호환되는 springdoc 3.2.0으로 구성합니다.

근거: [Spring Boot 3.5 마지막 OSS 릴리스](https://spring.io/blog/2026/06/25/spring-boot-3-5-16-available-now/), [springdoc 호환성 표](https://springdoc.org/#what-is-the-compatibility-matrix-of-springdoc-openapi-with-spring-boot).
