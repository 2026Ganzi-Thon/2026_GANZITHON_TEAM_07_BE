[README로 돌아가기](../README.md)

## 현재 상태

Spring Boot 프로젝트 구성 예정이며, 확정되거나 구현된 엔드포인트는 없습니다. Swagger / OpenAPI 도입 여부와 명세서 URL도 미정입니다.

## 기획에서 도출한 API 검토 범위

아래는 API 설계 시 검토할 기능 영역이며, 엔드포인트나 요청·응답 계약이 확정된 것은 아닙니다.

| 기능 영역 | 관련 기능 | 설계할 내용 |
| :--- | :--- | :--- |
| 감정 기록 / AI 대화 | F-01~F-03 | 입력, 대화 문맥, 응답 및 저장 시점 |
| 말랑이 추천 | F-04 | 감정과 추천 결과의 연결 |
| 말랑이 / 사운드 | F-05~F-06, F-10 | 클라이언트·백엔드 책임, API 필요 여부 |
| 마음 보관함 | F-07 | 기록 목록 및 상세 열람 |
| 분석 / 인사이트 | F-08~F-09 | 분석 대상, 수행 주기, 결과 조회 |

기능 정의는 [기능 명세서](features.md)를 참고합니다.

## 엔드포인트 상세 작성 양식

- **기능 / 관련 요구사항:** [기능 명세서](features.md)의 기능 ID
- **Method / URI:**
- **구현 상태:** 설계 / 구현 중 / 구현 완료
- **인증 / 권한:**
- **Headers:**
- **Path / Query Parameters:** 이름, 타입, 필수 여부, 제약조건
- **Request Body:** 필드 정의와 유효한 요청 예시
- **성공 응답:** HTTP 상태 코드, 필드 정의, 응답 예시
- **실패 응답:** 조건별 HTTP 상태 코드, 오류 코드, 응답 예시
- **처리 규칙:** 중복 요청, 동시 요청, 접근 제한 등 합의된 정책

실제 구현과 검증 결과를 기준으로 예시를 작성합니다. 인증 토큰과 개인정보는 예시에 포함하지 않습니다.
