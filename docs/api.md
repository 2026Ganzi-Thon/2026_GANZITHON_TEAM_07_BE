## 현재 상태

Spring Boot 프로젝트 구성 예정이며, 확정되거나 구현된 엔드포인트는 없습니다. Swagger / OpenAPI 도입 여부와 명세서 URL도 미정입니다.

## 공통 규약

| 항목 | 상태 |
| :--- | :--- |
| 로컬 / 배포 Base URL | 미정 |
| API 경로 및 버전 정책 | 미정 |
| 요청·응답 Content-Type | 미정 |
| 인증 방식 및 권한 | 미정 |
| 공통 응답 / 오류 형식 | 미정 |
| 날짜·시간 형식 및 시간대 | 미정 |
| 페이지네이션 규칙 | 미정 |

## 엔드포인트 상세 작성 양식

- **기능 / 관련 요구사항:** [기능 명세서](features.md)의 기능 ID
- **Method / URI:**
- **구현 상태:** 설계 / 구현 중 / 구현 완료
- **인증 / 권한:**
- **Headers:**
- **Path / Query Parameters:** 이름, 타입, 필수 여부, 제약조건
- **Request Body:** 필드 정의와 유효한 요청 예시
- **성공 응답:** HTTP 상태 코드, 필드 정의, 응답 예시
- **실패 응답:** 조건별 HTTP 상태 코드, 오류 코드, 응답 예시
- **처리 규칙:** 중복 요청, 동시 요청, 접근 제한 등 합의된 정책

실제 구현과 검증 결과를 기준으로 예시를 작성합니다. 인증 토큰과 개인정보는 예시에 포함하지 않습니다.
