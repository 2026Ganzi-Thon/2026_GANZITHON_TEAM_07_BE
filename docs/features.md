## 기능 상세 작성 양식

- **기능 ID / 이름:**
- **목적:** 사용자가 해결하려는 문제
- **사용자 / 권한:** 기능을 사용할 수 있는 대상
- **선행 조건:** 실행 전에 만족해야 하는 조건
- **기본 흐름:** 입력부터 결과까지 순서대로 작성
- **처리 규칙:** 검증 조건, 상태 변경, 중복 처리 정책
- **예외 흐름:** 실패 조건과 사용자에게 전달할 결과
- **완료 조건:** 성공·실패를 확인할 수 있는 구체적인 기준
- **관련 API:** [API 명세서](api.md)의 해당 항목 링크
- **관련 데이터:** [데이터베이스 설계](database.md)의 해당 항목 링크
- **관련 이슈 / PR:** 팀 저장소 링크
- **구현 상태:** 정의 중 / 구현 예정 / 구현 중 / 완료

요구사항과 구현 결과가 다르면 차이와 남은 작업을 함께 기록합니다.
