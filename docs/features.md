## 범위와 상태

사용자가 제공한 기획안의 기능을 정리했습니다. 모든 기능은 기획 단계이며 구현되지 않았습니다. 전체 기획 기능과 MVP 범위는 구분하며, MVP 포함 여부는 아직 미정입니다. 기능 ID는 이 문서에서 참조하기 위한 식별자입니다.

기반 작업으로 Java 21·Spring Boot·MySQL 연결·Swagger와 기능별 헥사고날 구조, `GET /api/v1/health`를 구성했습니다. F-01~F-10 업무 기능의 구현 상태는 변경되지 않았습니다.

## AI 대화와 감정 기록: F-01~F-04

텍스트 또는 음성으로 고민을 표현하고 AI 질문에 답하면서 감정을 구체화합니다. AI가 사용자의 감정을 대신 판단하고 해결하기보다 자기 이해를 돕는 대화를 지향합니다. 대화 이후 맞춤형 공감·조언과 감정 기반 말랑이 추천을 제공할 계획입니다.

### 기획에 제시된 대화 방향

- **목적:** 질문과 답변으로 사용자가 자신의 감정을 이해하도록 지원합니다.
- **입력:** 사용자의 고민과 이어지는 답변입니다.
- **처리·출력:** 대화 맥락을 바탕으로 공감, 후속 질문, 생각 정리를 제공합니다. 즉각적인 해결책 제시보다 감정과 생각의 구체화를 우선합니다.
- **참고 접근:** CBT를 참고한 상황·생각의 재해석, 소크라테스식 문답, SFBT를 참고한 강점·문제가 덜했던 순간·척도 질문입니다. 질문 예시와 적용 순서는 미정입니다.
- **주요 분석 대상:** 사건, 상황, 감정, 감정 강도, 감정 유발 요소, 사용자의 생각, 욕구, 원하는 결과입니다. 분석 대상이 모두 필수 질문이나 저장 필드로 확정된 것은 아닙니다.
- **종료 방향:** 감정과 상황이 충분히 구체화되었을 때 종료한다는 기획 방향이 있습니다. 충분함의 판단 기준과 사용자 종료 방식은 미정입니다.

결정할 사항:

- 대화 시작·종료 기준과 기록 저장 시점
- 질문 전략, AI 연동 기술, 대화 문맥 유지 방식
- 음성 처리 방식과 입력 제한, 실패 시 처리
- 감정 분류 기준과 조언·추천의 입력 및 출력 형식

설계 검토 자료: [AI 감정 대화 제어 설계안](ai-dialogue-design.md). BE의 실행 통제, AI의 질문 전략 선택, 상태·근거 관리와 검증 방안을 제안합니다. 미채택 설계이며 구현 상태와 MVP 범위를 바꾸지 않습니다.

## 말랑이 경험: F-05~F-06, F-10

말랑이는 감정 환기를 위한 인터랙션 도구입니다. 사용자의 터치·드래그에 따라 형태가 변형되고 이에 맞는 ASMR 사운드를 제공합니다. 화면 우측 하단 원형 메뉴에서는 감정 기록하기, 수면 모드, 마음 보관함으로 접근합니다.

### 진입과 종류 선택

메인 화면에서는 중앙의 기본 말랑이를 터치하거나 감정 기록하기 버튼을 선택합니다. 말랑이를 먼저 만지는 흐름과 감정을 먼저 기록하는 흐름을 모두 제공합니다. 상세 메뉴 버튼은 우측 하단에 둡니다.

인터랙션 화면 상단 버튼에서 말랑이 종류를 변경하며, 선택한 종류로 화면을 바꿉니다. 사용한 종류의 저장은 기획상 가능한 항목으로 제시되었으며, 저장 여부·시점·활용 방식은 미정입니다.

| 종류 | 기획상 주요 감정 | 인터랙션 방향 |
| :--- | :--- | :--- |
| 슬랑이 | 불안 / 우울 | 천천히 만지기 |
| 스퀴시 | 속상함 / 슬픔 | 부드럽게 누르기 |
| 왁뿌볼 | 분노 / 스트레스 | 강하게 누르기 |
| 커스텀 | 사용자 선택 | 사용자 지정 |

기획 원문의 일반 말랑이 조작 규칙을 아래에 기록합니다. 종류명 ‘슬랑이’와의 대응 및 최종 표기는 확인이 필요합니다. 감정별 연결은 추천 방향이며 추천 알고리즘이나 효과 검증 결과를 의미하지 않습니다.

### 말랑이·스퀴시 조작 규칙

| 입력 | 말랑이 | 스퀴시 |
| :--- | :--- | :--- |
| Tap | 터치 위치가 눌림 | 터치 위치가 눌림 |
| Long Press | 터치 위치가 지속적으로 압축됨 | 터치 위치가 지속적으로 압축됨 |
| Drag | 드래그 방향으로 늘어남 | 드래그 방향으로 늘어나며 말랑이보다 변형이 작음 |
| Release | 3초간 조작이 없으면 5초에 걸쳐 원형 복원 | 3초간 조작이 없으면 3초에 걸쳐 원형 복원 |
| 반복 터치 | 눌리는 정도가 달라짐 | 눌리는 정도가 달라짐 |

복원 시간은 기획 초깃값이며 구현하며 조정할 수 있습니다. 조작별 ASMR 사운드, 최대 변형량과 반복 터치에 따른 변형 규칙은 미정입니다.

### 왁뿌볼·커스텀

왁뿌볼은 스퀴시 위에 왁스를 덧씌운 구조입니다. Tap으로 터치 위치의 왁스를 깨고, 반복 터치로 연속해서 깹니다. 왁스가 모두 깨진 뒤에는 Long Press, Drag, Release에 스퀴시와 같은 규칙을 적용합니다. 왁스 초기화 방식과 조작별 사운드는 미정입니다.

커스텀 말랑이는 갤러리 사진을 선택해 말랑이 외형에 적용하고, 사용자 선택에 따라 저장·삭제하는 구상입니다. 핵심 감정 케어 기능이 아니므로 개발 우선순위에서 제외합니다. 전체 MVP 범위나 사진 처리·저장 정책은 확정하지 않습니다.

결정할 사항:

- 말랑이 최종 명칭과 구체적인 감정별 추천 기준
- 형태 변형·ASMR의 제어 규칙과 리소스 제공 방식
- 수면 모드의 동작, 종료 조건, 사운드 정책
- 클라이언트와 백엔드 사이의 기능별 책임

## 장기 감정 케어: F-07~F-09

감정 기록을 지속적으로 축적하고 마음 보관함에서 열람합니다. 시간에 따른 감정 변화, 반복적인 감정 패턴과 스트레스 요인을 분석하여 개인화 인사이트를 제공할 계획입니다.

결정할 사항:

- 보관함 정렬·검색·상세 열람 범위
- 기록 수정·삭제 및 보관 정책
- 분석 대상 데이터, 최소 기록량, 분석 주기
- 패턴·취약점·스트레스 요인의 표현 기준과 인사이트 제공 시점

## 구현 전 공통 결정 사항

- 사용자 식별과 인증·권한 정책
- MVP 우선순위와 기능별 완료 조건
- 요청 실패·중복 요청·AI 응답 지연 처리
- 데이터 저장 구조와 기능별 [API 계약](api.md)
- 화면 플로우와 ‘마음 보관함 / 마음 기록함’ 명칭 확정
