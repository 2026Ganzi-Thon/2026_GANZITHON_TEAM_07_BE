# 기능 명세서

[README로 돌아가기](../README.md) · [AI 감정 대화 시스템](emotional-dialogue/README.md) · [서비스 기획안](service-overview.md) · [API 명세서](api.md) · [데이터베이스 설계](database.md)

## 범위와 상태

사용자가 제공한 PM 확정 기획서(서비스명: **테슬랑**)를 바탕으로 전체 기능과 해커톤 MVP 개발 범위를 정의한 문서입니다.
현재 백엔드는 Spring Boot 4 기반 인프라와 F-00 인증 API를 제공합니다. F-00은 로컬·소셜 로그인, JWT 갱신·폐기, 본인 프로필 조회까지 구현했습니다. 그 외 업무 기능은 아직 구현하지 않았으며, 본 명세서의 MVP 필수 기능(F-01~F-04, F-07, F-08, F-09, F-10)을 우선 개발 대상으로 삼습니다.

## 1. 사용자 인증 및 식별 (F-00, MVP 필수)

- **목적:** 사용자의 개인화된 감정 기록과 상담 내역을 안전하게 격리·보관하고 본인만 조회할 수 있도록 함
- **기능 명세:**
  - **다중 인증 지원:** 로컬 이메일/비밀번호 가입 및 주요 소셜 로그인(**카카오**, **디스코드**, 구글) Authorization Code 방식 지원
  - **동일 이메일 가입 거부 정책:** 동일한 이메일로 이미 다른 공급자(LOCAL 또는 타 소셜)에 가입되어 있는 경우, 계정 자동 병합의 보안 리스크를 막기 위해 신규 가입을 거부(HTTP 409)하고 기존 공급자로 로그인하도록 명확히 안내
  - **최초 로그인 자동 가입 (JIT):** 소셜 첫 로그인 시 별도 입력 없이 즉시 회원 생성 + 기본 말랑이(슬랑이) 인벤토리 자동 해금 + 서비스 JWT 발급
  - 로컬 이메일 가입에도 기본 말랑이(슬랑이)를 지급하며, 기존 회원은 V2 마이그레이션에서 누락된 기본 말랑이를 보정
  - 인증 성공 시 JWT (Access Token 24시간 / Refresh Token 14일) 발급
  - **Refresh Token Rotation (RTR):** 토큰 재발급 요청(`POST /api/v1/auth/refresh`) 시 기존 Refresh Token을 DB에서 검증 후 폐기(`is_revoked = true`)하고 새로운 쌍을 발급하여 토큰 탈취 방어
  - **로그아웃 및 토큰 폐기:** 로그아웃(`POST /api/v1/auth/logout`) 시 해당 회원의 활성 Refresh Token을 즉시 폐기 처리
  - 모든 감정 상담 세션 및 기록 조회 API에 Bearer 토큰 검증 적용

## 2. AI 감정 대화 및 생각 정리 (F-01, F-02, F-03, F-07, MVP 필수)

> 7단계 상담 라이프사이클의 세부 데이터 규약과 질문 전략은 **[AI 감정 대화 시스템: 7단계 상담 프로세스](emotional-dialogue/process.md)**를 참조하세요.

AI는 사용자의 고민에 일방적인 해결책을 제시하지 않고, 질문을 통해 사용자가 자신의 감정과 생각을 명확히 들여다보도록 돕습니다.

### 4대 통합 심리 상담 기법
- **CBT (인지행동치료):** 생각·감정·행동의 상호작용 분석, 자동적 사고 분리
- **소크라테스식 대화법:** 근거, 반례, 대안적 관점을 묻는 질문으로 생각의 유연성 유도
- **SFBT (해결중심 단기치료):** 예외 상황 발견, 과거 대처 자원 탐색, 실천 가능한 작은 변화 도출
- **NVC (비폭력 대화):** 감정 이면에 숨겨진 사용자의 핵심 욕구(Need) 탐색

### 7단계 상담 프로세스 및 데이터 규약

```
[STEP 01] 감정 및 상황 탐색 (Situation)
   │
[STEP 02] 감정과 상황 구조화 (Emotion, Pre-Intensity [0-10], Trigger, Thought)
   │
[STEP 03] 생각의 유연성 탐색 (Alternative Thought, Need)
   │
[STEP 04] 해결 가능성과 작은 변화 발견 (coping)
   │
[STEP 05] 감정 정리 및 실천 (Action)
   │
[STEP 06] 말랑이 추천 및 감정 환기 (Post-Intensity [0-10], Malangi Recommendation)
   │
[STEP 07] 감정 기록 저장 및 요약 (Final Save to Record)
```

1. **STEP 01. 감정 및 상황 탐색 (Situation)**
   - 고민과 발생 사건 파악, 공감적 경청으로 표현 유도
2. **STEP 02. 감정과 상황 구조화 (CBT)**
   - 대표 감정 1개 + 부가 감정 1개 지정
   - **사전 감정 강도(Pre-Intensity):** 0~10점 범위에서 사용자가 직접 입력 (AI 임의 추정 금지)
   - 감정 유발 요인(`Trigger`) 및 최초 자동적 사고(`Thought`) 분리
3. **STEP 03. 생각의 유연성 탐색 (소크라테스식 대화)**
   - 최초 생각에 대한 근거와 반례 탐색 ➔ 새로운 관점(`Alternative Thought`) 발견
   - 그 상황에서 진정으로 원했던 내면의 욕구(`Need`) 확인
4. **STEP 04. 해결 가능성과 작은 변화 발견 (SFBT)**
   - 문제가 덜했던 순간이나 지금까지 버텨온 방식(`coping`) 탐색
5. **STEP 05. 감정 정리 및 실천 (CBT+SFBT)**
   - 사용자가 납득하고 수용할 수 있는 대안적 생각 정리
   - 스스로 실천해볼 수 있는 현실적인 작은 행동(`Action`) 선택
6. **STEP 06. 말랑이 추천 및 감정 환기**
   - 상담 요약 및 새로운 관점 확인
   - **사후 감정 강도(Post-Intensity):** 0~10점 범위에서 사용자가 직접 재입력
   - 감정 상태에 맞는 말랑이(슬랑이, 스퀴시, 왁뿌볼) 추천
7. **STEP 07. 감정 기록 저장 (마음 기록함)**
   - 전체 상담 내용 구조화 후 `EmotionRecord`로 최종 영구 저장

### 상담 대화 운영 규칙
- 한 번에 핵심 질문 하나만 제시
- 질문에 앞서 사용자의 감정을 온전히 인정·공감
- 이미 확인된 정보는 반복 질문하지 않음
- 사용자의 생각을 결코 직접 부정하거나 틀렸다고 평가하지 않음
- 사용자가 원하는 시점에 언제든 상담을 종료할 수 있음

## 3. 위기 대응 및 안전 보호 규칙 (F-09, MVP 필수 - Safety Guardrail)

> 상세한 6대 안전 규칙과 데이터 격리 정책은 **[AI 감정 대화 시스템: 위기 대응 규칙 및 안전 가드레일](emotional-dialogue/safety.md)**을 참조하세요.

정신건강 및 심리 케어 서비스의 안전성을 위해 전체 대화 흐름에 최우선 적용되는 규칙입니다.

### 1) 위험 신호 2중 감지 체계
- **1차 (서버 룰 기반):** 백엔드에서 메시지 수신 즉시 자해, 자살, 타해, 폭력/학대 관련 키워드 및 정규식 검사
- **2차 (AI 안전 분류):** AI 모델 프롬프트 및 안전 분류기를 통해 의도 검사
- 과장된 일상 표현("과제 때문에 죽겠다 ㅋㅋ" 등)이 명백한 경우를 제외하고는 보수적으로 위험 신호로 판정

### 2) 감지 시 시스템 즉각 조치
- 진행 중이던 모든 AI 질문, 생각 정리, 관점 탐색을 **즉시 중단**
- 안전 안내 메시지 출력:
  > “혼자 감당하지 않아도 괜찮아요. 지금은 마음의 문제를 해결하기보다 안전하게 도움을 받는 것이 중요해요.”
- **상담 연결(핫라인) 화면으로 즉시 전환**

### 3) 긴급 상담 핫라인 정보 제공
- **자살예방상담전화:** 109 (24시간)
- **정신건강위기상담전화:** 1577-0199 (24시간)
- **청소년 상담전화:** 1388
- **긴급 구조/신고:** 112 / 119
- 화면을 닫아도 메뉴에서 언제든 재확인 가능하도록 보장

### 4) AI 금지 사항 준수
- 의학적 진단 또는 병명 언급 금지
- 약물 복용이나 치료 방법 등 의료 행위 조언 금지
- 자신을 전문 상담사나 의사로 소개 금지
- 사용자의 생각을 "비합리적", "틀렸다"고 비난·평가 금지

### 5) 위험 기록 데이터 정책
- 위기 신호가 감지된 기록은 `risk_flag = true`, `status = 'ABORTED_RISK'`로 세션 테이블에만 표기되고, 상담 결과(`counseling_results`)는 생성되지 않음
- `risk_flag` 기록은 통계 및 개인화 패턴 분석 데이터에서 **완전 제외**
- **일원화된 세션 삭제권 보장:** 결과 테이블이 없는 위기 세션도 세션 삭제 API(`DELETE /api/v1/counseling/sessions/{sessionId}`)를 통해 즉시 영구 삭제 가능

## 4. 말랑이 경험 및 추천 (F-04, F-05, F-06, F-10)

말랑이는 감정 환기를 위한 감각적 상호작용 도구입니다.

### 말랑이 종류 및 감정별 추천 (F-04)

| 종류 | 대응 감정 | 인터랙션 특징 |
| :--- | :--- | :--- |
| **슬랑이** | 불안, 우울 | 천천히 만지기. 부드럽고 느린 복원 (기본 보유) |
| **스퀴시** | 속상함, 슬픔 | 부드럽게 누르기. 말랑이보다 작은 변형, 빠른 복원 |
| **왁뿌볼** | 분노, 스트레스 | 강하게 누르기. 왁스 파쇄 후 내부 스퀴시 조작 |
| **커스텀** | 사용자 지정 | 사진 업로드 외형 적용 (MVP 제외) |

- **추천 시 자동 해금 규칙 (Unlock on Recommendation):**
  - 사용자가 상담을 완료하고 자신의 감정에 적합한 말랑이를 추천받았을 때, 해당 말랑이가 아직 잠겨있다면(`is_unlocked = false`) 추천 즉시 자동으로 해금(`is_unlocked = true`) 처리되어 감각적 환기 경험을 바로 시작할 수 있습니다.
  - 상담 완료 응답에 `isNewlyUnlocked: true` 플래그를 함께 전달하여 클라이언트에서 해금 연출을 제공합니다.

### 터치 조작 및 복원 규칙 (F-05)
- **Tap:** 터치 위치 눌림 (왁뿌볼의 경우 왁스 깨짐)
- **Long Press:** 터치 위치 지속 압축
- **Drag:** 드래그 방향으로 형태 확장
- **Release:** 3초간 미조작 시 원래 형태로 자동 복원 (슬랑이 5초, 스퀴시 3초에 걸쳐 복원)
- **ASMR 사운드 (F-06):** 조작 상태에 따른 감각적 효과음 제공 (FE 중심, MVP 권장)

## 5. 마음 기록함 (F-08, MVP 필수)

- **기록 목록 조회:** 날짜순 상담 이력 리스트 (대표 감정 아이콘, 상담 요약 한 줄, 감정 강도 변화)
- **기록 상세 조회:**
  - 상담 일시
  - 대표 감정 및 부가 감정
  - 상담 전/후 감정 강도 (Pre/Post Intensity)
  - 초기 자동적 사고(Thought)와 새로운 대안적 관점(Alternative Thought)
  - 사용자가 선택한 대처 방법(coping)과 작은 실천 행동(Action)
  - 추천받은 말랑이 유형
  - AI 상담 전체 요약
- **기록 삭제:** 사용자 요청 시 해당 상담 데이터 및 연관 메시지 완전 삭제

## 6. MVP 후순위 기능 (F-11 ~ F-15)

다음 기능은 초기 핵심 가치 검증(상담 정리, 말랑이 환기, 감정 변화 기록) 이후 고도화 단계에서 구현합니다.

- **F-11. 월별 감정 통계:** 누적 데이터 기반 월간 감정 빈도, 변화 추이
- **F-12. AI 사고 패턴 누적 분석:** 반복되는 스트레스 요인 및 자동적 사고 유형 도출
- **F-13. 과거 대처 방법 자동 추천:** 이전 상담에서 효과적이었던 대처 자원 재추천
- **F-14. 수면 모드 및 타이머:** 백색소음/자연음 재생 및 무드등 시각 효과
- **F-15. 커스텀 사진 말랑이:** 사용자 사진 텍스처 매핑

## 7. MVP 개발 원칙 6개 수칙

1. AI가 사용자의 감정이나 생각을 임의로 판단하지 않는다.
2. 사용자가 말하지 않은 정보는 추측하여 기록하지 않는다.
3. 감정 강도는 AI가 추정하지 않고 사용자가 직접 입력한다.
4. 상담을 통해 새로운 생각을 강요하지 않고 사용자가 스스로 발견하도록 돕는다.
5. AI 상담은 전문적인 심리 상담 및 치료를 대체하지 않는다.
6. 위기 신호가 감지되면 일반적인 상담보다 안전 안내를 최우선으로 처리한다.
